# Themes

Each theme is one CSS file here (`<name>.css`) defining the shadcn CSS custom
properties (`--background`, `--primary`, `--radius`, etc.) plus its `.dark`
variant. Components never reference a theme directly — they only use Tailwind
utilities (`bg-primary`, `text-muted-foreground`, ...) that resolve through
these variables, so any theme "just works" with every component.

## The default theme

`default.css` is imported unconditionally by `src/index.css` and scoped to
bare `:root`. That makes it the automatic fallback: an app that does nothing
gets the default theme. It's generated by
[Style Dictionary](https://styledictionary.com/) (`scripts/transform-tokens.mjs`)
from the Figma token export in `design.tokens/themes/default/*.tokens.json` —
see the root [README's Theming section](../../../README.md#theming).

The sibling `../theme-scale.css` (typography/spacing/radius scale, `--color-*`
aliases) is shared across all themes, not per-theme — see the note at the top
of `scripts/transform-tokens.mjs`.

## Adding another theme

1. Export the new theme's tokens from Figma into
   `design.tokens/themes/<name>/*.tokens.json` (same file shape as
   `design.tokens/themes/default/`).
2. Run `npm run transform-tokens -- --theme=<name>` to generate
   `src/styles/themes/<name>.css` and `src/tokens/themes/<name>/*.ts`. Unlike
   `default.css`, `<name>.css`'s rules are scoped to `:root[data-theme="<name>"]`
   (and `:root[data-theme="<name>"].dark` for its dark variant) — the extra
   attribute selector gives it higher specificity than bare `:root`, so it
   reliably overrides the default theme wherever it's active, regardless of
   CSS import order.
3. Register the new theme in `src/tokens/index.ts` and document its name in
   the root README so consumers know it exists.

## Using a non-default theme in a consuming app

1. Import the theme's CSS (either `@import` the generated file, or copy its
   contents into the app's own stylesheet).
2. Set `data-theme="<name>"` on `<html>` (or any ancestor of the app root).
   The optional `ThemeProvider` in `src/components/theme-provider.tsx` does
   this for you: `<ThemeProvider theme="<name>">...</ThemeProvider>`.
3. Don't set it (or pass `theme="default"` / omit the prop) to get the
   default theme — no extra setup required.
